# 8051 Experiments

# 8051 Microcontroller | Embedded Systems Programming

## Overview

This project documents my hands-on experience with the **8051 microcontroller (AT89S52)** as part of the Fundamentals of Internet of Things laboratory.

The experiments focus on embedded C programming, microcontroller architecture, hardware interfacing, peripheral control, and real-time embedded system concepts.

The primary objective was to understand how software interacts directly with hardware through registers, GPIO ports, timers, interrupts, and communication interfaces.

## Technical Skills Developed

- **Embedded C Programming:** Developed firmware for microcontroller-based applications.
- **GPIO Interfacing:** Controlled LEDs and implemented multiple LED sequencing patterns.
- **Digital Input Handling:** Interfaced switches and matrix keypads for user-controlled operations.
- **Display Interfacing:** Worked with seven-segment displays and character LCDs.
- **Timers and Interrupts:** Implemented timer-based LED control using hardware timer interrupts.
- **UART Communication:** Implemented serial data transmission, reception, and echo functionality.
- **Peripheral Integration:** Combined multiple hardware components into interactive embedded applications.

## Key Implementations

### LED Control and GPIO Programming
Implemented LED blinking, sequencing patterns, and switch-controlled operations using digital GPIO pins.

### Keypad and Display Interfacing
Developed keypad-scanning logic and interfaced seven-segment displays to represent user inputs. Implemented character LCD applications for displaying messages, counters, and keypad-controlled character movement.

### Timer and Interrupt Programming
Configured 8051 hardware timers and interrupts to generate periodic events and control LED behavior.

### UART Serial Communication
Implemented UART-based communication, including serial message transmission and interrupt-driven data reception with buffering.

## Tools and Technologies

- **Microcontroller:** AT89S52 (8051 Architecture)
- **Programming Language:** Embedded C
- **Development Environment:** Keil µVision
- **Core Concepts:** GPIO, Timers, Interrupts, UART, Keypad Scanning, LCD and Seven-Segment Interfacing

## Learning Outcomes

Through these experiments, I developed a practical understanding of register-level programming, embedded firmware development, digital hardware interfacing, and microcontroller communication.

This foundation supports my continued learning in **STM32 development, ARM Cortex-M microcontrollers, embedded systems, and Internet of Things applications**.
